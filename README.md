# My Quran App 
([See It Here](https://cluster314.github.io/quran-app)) 
This is a Quran app that I made.
Features:

- **Quran Reading**
  - Indo-Pak Quran Arabic script
  - Verse-by-verse reading
  - Arabic-only reading
  - Translation reading
  - Mushaf (page-style) reading
  - Quran page layout
  - Quran text display

- **Quran Navigation**
  - Surah navigation
  - Juz navigation (30 Juz)
  - Page navigation
  - Individual Ayah navigation
  - Verse range navigation
  - Surah selection dropdown
  - Starting Surah and Ayah selection
  - Ending Surah and Ayah selection
  - URL hash-based navigation
  - Direct Quran location navigation

- **Quran Audio Player**
  - Play recitation
  - Pause recitation
  - Stop recitation
  - Individual Ayah playback
  - Selected Ayah range playback
  - Current playback status
  - Current recitation information
  - Sticky bottom audio player
  - Audio playback while navigating
  - Mishari Rashid al-Afasy recitation

- **Audio Playback Settings**
  - Playback speed control (0.75x, 1.0x, 1.25x, 1.5x, 2.0x)
  - Audio range selection
  - Automatic next Ayah playback
  - Playback completion handling

- **Ayah Repetition and Memorization**
  - Repeat individual Ayah
  - Infinite Ayah repetition
  - Custom Ayah repetition count
  - Repeat selected Ayah range
  - Infinite range repetition
  - Custom range repetition count
  - Automatic progression between verses
  - Automatic stopping after selected repetitions

- **Reading Modes**
  - Verse mode
  - Arabic mode
  - Translation mode
  - Mushaf mode

- **Appearance and Themes**
  - Dark theme
  - Light theme
  - Sepia theme
  - OLED theme
  - Accent color customization
  - Diamond Blue accent
  - Gold accent
  - Emerald Green accent
  - Sunset Orange accent
  - Amethyst Purple accent
  - Persistent theme preferences
  - Persistent accent color preferences

- **Quran Verse Utilities**
  - Copy individual Quran Ayah
  - Copy Quran text to clipboard
  - Copy confirmation notification
  - Open corresponding Quran location on Quran.com

- **Reading Time Tracker**
  - Track total time spent in the application
  - Display time in minutes and seconds
  - Automatically update the timer
  - Save tracked time in local storage
  - Retain tracked time between visits

- **User Interface and Experience**
  - Responsive mobile layout
  - Desktop-friendly layout
  - Mobile-friendly navigation
  - Mobile-friendly audio controls
  - Arabic typography optimization
  - Loading indicators
  - Playback status indicators
  - Navigation dropdowns

- **Data and Storage**
  - Quran content integration
  - Quran.com API integration
  - Quran translation JSON dataset
  - Translation caching
  - Audio streaming
  - Browser local storage
  - Persistent user preferences
  - Quran page mapping data

- **External Integrations**
  - Quran.com integration
  - Quran.com verse links
  - Quran recitation audio sources
  - Quran content API

- **Technical Features**
  - URL hash-based navigation
  - Direct Quran position linking
  - Local preference persistence
  - Client-side state management
  - Cached translation data
  - Responsive rendering
  - Browser-based application

Hope you like it!
